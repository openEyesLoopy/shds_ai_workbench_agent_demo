기획서 버전: v1.7

[AS-IS]
현재 사용자 정보 조회 데모 화면에서는 [사용자 정보 조회] 버튼을 통해서만
이름, 나이, 전화번호의 기본 정보를 확인할 수 있음.

[TO-BE]
신규 [가입 일자 정보 조회] 버튼을 화면 상단에 추가한다.
버튼 클릭 시 아래 정보를 하단에 추가로 노출한다:
- 가입일자
- 가입 당시 사용자 정보
- 단말 OS 정보
- 접속 IP 정보

[요구사항 상세]
1. 기존 [사용자 정보 조회] 버튼과 결과 표시 영역은 그대로 유지한다.
2. 신규 버튼은 화면 상단, 기존 버튼 옆에 [신규] 뱃지와 함께 배치한다.
3. 신규 버튼 클릭 시 백엔드에 가입 일자 관련 정보를 요청하고,
   응답을 카드 형태 UI로 하단에 노출한다.
4. 백엔드 응답 모델에는 가입일자(joinDate), 단말 OS(deviceOS),
   접속 IP(ipAddress) 필드를 포함해야 한다.

[테스트 시나리오]
- [가입 일자 정보 조회] 버튼 클릭 시 신규 버튼 핸들러가 정상 동작해야 한다.
- 신규 목록에 가입일자, IP, OS 데이터가 노출 상태를 확인해야 한다.
- 기존 사용자 정보 조회 기능은 회귀 없이 그대로 동작해야 한다.
